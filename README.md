# Параллельная быстрая сортировка

## Запуск

```bash
./run.sh
```

Для отдельного запуска после сборки передайте тип сортировки:

```bash
out/bin/Release/quick_sort seq # последовательная
PARLAY_NUM_THREADS=4 out/bin/Release/quick_sort par # параллельная
```

## Тесты

```bash
./test.sh
```

Тесты сравнивают результат со `std::sort`, включая пустые массивы, повторы,
граничные значения `int` и размеры около границ блоков и порога параллельной
сортировки. Параллельная версия проверяется на одном и четырёх потоках.
